# 方舟剧场 v1.3.0

本版适配 PRTS 新版剧情演出引擎，保留适合移动端的游戏式顶部控制。

- 动态识别引擎入口与依赖，复用未变化的缓存，并显示引擎和画面资源加载进度。
- 修复 Android 慢网络下的自定义协议超时闪退，补充持久诊断与恢复日志。
- 修复背景音乐引子和循环段衔接时的加载停顿，并释放闲置音轨。
- 保持画面 16:9 比例，修复舞台获得焦点后出现的黄色边框。
- 完善手动/自动播放、三箭头动画、长按快进及退出操作。
- 剧情日志角色名单独成行，字号可在设置中调整。
- 书架分类、封面和横幅按变化增量更新，每天北京时间 22:00 检查一次。
- 自有代码与资源采用 AGPL-3.0-only；第三方版权内容保留原有授权，完整说明见应用关于页。

Android 手机选择 arm64-v8a APK；桌面平台选择对应系统安装包。
