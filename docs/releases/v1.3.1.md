# 方舟剧场 v1.3.1

本版完善新版 PRTS 剧情播放器，新增断点续播与已读 LOG 跳转，并改善启动速度和 Android 阅读体验。

- 新增本地断点续播，保存对白位置、选项和已读记录；再次进入可继续阅读或从头播放。剧情内容更新后不复用旧断点。
- 已读 LOG 支持点选或键盘跳转，恢复当时的分支；回跳后保留历史记录，并同步更新续播位置。另保留「查看全部文本」入口和设置中的字号调整。
- 绿色已读灯改为剧情实际播放结束后点亮，回看不会取消完成标记。旧版按停留时间生成的标记保留在本地，不再作为已读完的依据。
- 已验证的本地剧情可直接启动，后台轻量检查剧情修订号和引擎版本；新候选验证成功后在下次进入使用，检查失败保留可用缓存。
- 播放界面左上角设置新增「重载播放引擎」，可重新获取并重建引擎，保留可恢复的阅读进度。
- 修正正常退出、系统结束进程后重新进入时的异常退出误报，继续保留原生和前端诊断日志。
- 保留游戏式顶部操作、16:9 画面、自动播放、长按／Ctrl 快进及背景音乐引子与循环段衔接，并减少移动端加载和解码峰值。

Android 用户下载 `arkstage-v1.3.1-android-arm64-v8a.apk`。APK 由 GitHub Actions 构建、校验固定签名并自动上传，旁附 SHA-256 校验文件；桌面用户选择对应系统安装包。
