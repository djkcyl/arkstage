# 1.1.13 缓存、慢网络、自动资源更新及开源协议简报

- 用户提供的原生日志定位到 Wry 0.54.4 Android 自定义协议 `recv_timeout(10s).unwrap()`，而原资源请求可等待 45 秒。新增异步 IPC 资源缓存通道，模块导入、图片、字体、fetch / XHR 和按需音频优先准备本地字节；协议另有 8 秒独立响应保护，超时返回错误，迟到结果不重复响应。
- 利用新版哈希入口及适配器版本持久化桥接结果。未变的已验证剧情快照不重复启动校验或写盘；可变数据表、wiki HTML 与旧版依赖使用内容绑定的 HTTP 条件校验，保留离线回退。加载页提供引擎模块计数、体积及画面资源进度。
- 自动同步脚本批量探测分类和图片版本，无变化时提前结束；仅下载/转换变化内容。发现新主线、曲谱分类、联动及活动横幅，优先使用已有游戏 KV 映射，未知 KV 的新活动自动使用 PRTS 横幅。实际完整同步生成 97 张封面、90 张横幅；后续测试无变化检测约 1.6 秒，强制重建复用了 181 项图像处理结果、下载 0 项。
- 仅准备北京时间每天 22:00 的本地工作流配置，未经明确授权不得部署、启用或触发。发布前验证源文件 SHA、分类成员和已有图片完整性，失败不会覆盖远程已发布资源。
- 移除旧的播放器返回按钮开关，以及设置面板里重复的“退出阅读”；播放界面使用右上角“退出”。
- 项目自有代码和资源采用 AGPL-3.0-only，README、LICENSE、授权范围文件和关于页均明确排除 PRTS、鹰角网络及其他第三方内容，责任说明保留适用法律限定。AGPL 原文未修改，第三方软件/资源继续适用原有许可。


- BGM 引子和循环段会在交接播放前按序准备，旧 BGM 保持到下一首准备完成；过期请求取消解码，闲置音轨释放，避免循环段开始时才加载而产生停顿。
- 已弃用并移除误整合的远端 1.2.0 播放器实现、备用路径、辅助模块及新增依赖，版本回到独立的 1.1.13 测试线。未经明确要求禁止任何本地或云端 Git 操作，规则写入 AGENTS.md。

验证与本地测试包：

- 55 项 Rust 测试、前端回归、类型检查、生产构建及 lint 通过。
- 真实上游模块的桥接和音频实现通过回归；浏览器确认 BGM 补丁已安装，画面比例、顶部覆盖层、手势、日志布局/字号、冷缓存进度与重启复用均通过。
- 1.1.13 在 Android 15 / WebView 124 模拟器中阻断本应用 HTTPS 网络超过 12 秒，协议在 8072ms 返回 504，应用进程始终为 PID 4022，页面心跳继续运行；测试后恢复网络。用户的 Android 16 / WebView 156 真机尚待测试。
- 本地生成 arm64、x86_64 和双架构通用 APK。均为 1.1.13（versionCode 1001013），沿用此前测试签名；核对通用包内原生库与两个单架构包一致。产物、SHA-256 清单和验证记录位于 `build/artifacts/`。
