# 1.1.11 剧情播放器与 LOG 简报

日期：2026-11-03。

- 自动模式显示“自动”和三个小箭头，按旧版 PRTS `timer_auto` 的 400ms 节奏从一个递增到三个，再循环；手动模式仍只显示“手动”，不显示倍速框。
- 将右上角原“跳过”替换为“退出”，沿用原按钮位置，直接执行播放器页面的返回操作，不再跳转剧情段落。
- LOG 使用独立对话条目，角色名单独一行，正文位于下方；叙述不显示空角色名。标题和关闭按钮固定，已读记录打开时定位至末尾，全部文本从头查看。
- 应用设置页新增“剧情日志（LOG）字号”，范围 12–32px，默认 18px，提供预览并自动保存；播放器内不新增字号控件。
- LOG 保留原剧本行号以截取已读范围，将支持的排版标记转为可读文本，并通过 React 文本节点展示。仅在打开 LOG 时生成条目，避免快进期间反复解析整份剧本。

验证：新增 LOG 的角色/正文分离、行号截取、叙述及换行、字号持久化与非法值回退测试。完整静态检查通过，包含 52 项 Rust 测试及 24 项前端测试，另通过 ESLint、TypeScript 与生产构建。

浏览器使用真实 PRTS QBOFHASl 引擎和缓存媒体，验证三箭头各动画阶段、退出回调、日志分行与滚动、设置保存及新播放器应用字号；同时回归五种视口的 16:9 比例、手动/自动、长按/Ctrl 快进、触摸取消与选项等待。测试使用独立浏览器与 Tauri 调用替身；仍需在用户设备中测试实际 WebView 和触摸体验。

按构建文档生成 Android arm64、x86_64、通用 APK，Windows 安装版和便携版，以及 Linux deb/rpm。构建产物、验证记录和 SHA256SUMS 位于忽略目录 `build/artifacts/`。
