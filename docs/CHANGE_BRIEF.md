## 修改目的

增强 PRTS 演出引擎启动与热更新的可靠性，处理播放卡在加载阶段、预下载资源解析失败，以及异常上游快照覆盖可用缓存的问题。

## 主要变化

- **引擎执行与诊断**：将同页的经典脚本合并为一个程序，在 iframe 内执行；仅在 eval 策略受限时回退到 Blob 脚本。增加依赖、源码和启动健康检查，预加载异常会明确报错。
- **验证与回滚**：全局引擎及剧情快照升级到 v5 缓存，候选版本须通过结构检查、隔离 iframe 启动、资源引用审计和清单生成后才写入缓存。保存上一代剧情快照，实际播放启动失败时在新 iframe 中回退，并显示原因；失败的请求不再被永久复用，后续可重试。
- **上游解析兼容**：通过脚本语义标记识别引擎，兼容上游 class 与数据标签变化；剧情提取选择最长的非空数据块，避免误用较短的重复模板示例，页面标题缺失时使用请求的剧情标题。
- **角色与资源处理**：修复分组角色引用 `$G` / `#N$G` 的偏移和越界回退；从当前快照发现资源域名，使新增域名的资源也能经本地缓存协议加载。
- **网络与缓存维护**：增加连接及请求超时、最多三次请求尝试、响应类型与体积检查；扩充 DOM、音频表和引擎能力诊断；章节缓存删除覆盖 v3、v4、v5 及 v5 上一代快照。
